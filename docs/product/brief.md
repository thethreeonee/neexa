# Neexa 产品概要

状态：初始梳理，尚未形成完整 PRD。

来源：[项目讨论](https://chatgpt.com/share/6ad47b47-10a4-83ea-a8c9-4542e230298c)。

## 已明确的方向

Neexa 是一款主要供个人使用的 macOS 原生启动器与 AI 助手，统一应用、文件、系统操作、内置工具、扩展插件和 AI 的入口。

期望融合的能力包括：

- Asky 的原生 UI、窗口交互、AI 对话、Agent 与 MCP 能力。
- Tinycast 的内置效率工具，包括计算器、窗口管理、Snippets、Quicklinks、系统操作、快捷指令与日历等。
- Raycast 插件生态，以扩展补充内置能力，并保持原生界面体验。

先梳理想要的产品，再决定现有代码如何复用；不预设 Asky 的架构为主体。
